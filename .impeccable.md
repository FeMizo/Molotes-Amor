## Design Context

### Users
Vecinos de la ciudad que ordenan comida local desde su teléfono. Clientes habituales del negocio — familias, parejas, grupos pequeños — que conocen la marca y piden para fin de semana o entre semana. El momento de compra es personal y cercano, no transaccional ni apresurado.

### Brand Personality
Cálido, casero, personalizado. El negocio no es una cadena ni una startup — es un puesto de comida real con identidad propia. El tono debe sentirse como hablarle a alguien conocido, no como una app genérica.

### Aesthetic Direction
Artesanal mexicano contemporáneo. Light theme (la comida se ve mejor en fondo claro, y el momento de compra es diurno/vespertino). Paleta cálida ya definida: crema, terracota, sepia, mostaza, olivo. 

**Anti-referencia**: No básico, no genérico, no "landing page de IA". Nada de blobs decorativos, grids idénticos de 3 columnas, tipografía Cormorant+Inter, floating social proof cards, o números grandes "01. 02." como feature items.

### Design Principles
1. **Calidez sobre pulcritud** — prefiere lo imperfecto y personal sobre lo clínico y uniforme
2. **Sin decoración vacía** — cada elemento visual tiene función; no blobs, no glassmorphism, no elementos que flotan solo para verse "modernos"
3. **Composición editorial, no de template** — romper el grid cuando hay razón para hacerlo; jerarquía visual real, no simetría por defecto
4. **El producto es el protagonista** — las imágenes de comida mandan; la UI es soporte, no protagonista
5. **Español natural** — el copy debe sonar como lo dice alguien real, no como copy de startup traducido
